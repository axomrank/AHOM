# Catalogue and audit records

- `reference-manifest.json` and `.csv`: authoritative current paths, tradition, site, view type, period notes, attribution and checksums.
- `move-ledger.json`: original-to-current file moves; images were checked before and after moving.
- `organization-summary.json`: photograph counts by reference group.
- `thumbnails/`: gallery previews generated from the original reference files.
- `download_records/`: preserved download manifests, Commons metadata and logs with historical paths. Do not use these old paths to select images.
