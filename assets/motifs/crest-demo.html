The Ahom crest, as a CSS component

One element, one class. The gilt is a CSS mask over the traced ornament in crest.svg, so the colour and size come from CSS tokens, not from the artwork.

The CSS

.crest {
  --crest-ground: #8B4700;
  --crest-gilt: linear-gradient(168deg, #FCEE7A 0%, #F2D845 40%, #E0B634 80%, #F6DF62 100%);
  --crest-width: 22rem;
  position: relative;
  display: block;
  width: var(--crest-width);
  max-width: 100%;
  aspect-ratio: 270 / 187;
  background: var(--crest-ground);
  isolation: isolate;
}

.crest::before {
  content: "";
  position: absolute;
  inset: 0;
  background: var(--crest-gilt);
  -webkit-mask: url("crest.svg") center / 100% 100% no-repeat;
          mask: url("crest.svg") center / 100% 100% no-repeat;
}

.crest--maroon  { --crest-ground: #5A0E1C; }
.crest--bare    { --crest-ground: transparent; --crest-gilt: #B8862B; }
.crest--sm      { --crest-width: 12rem; }
.crest--lg      { --crest-width: 36rem; }

.crest--organism::before {
  -webkit-mask: url("organism.svg") center / 100% 100% no-repeat;
          mask: url("organism.svg") center / 100% 100% no-repeat;
}

.crest--shine::before {
  background-size: 240% 100%;
  animation: crest-sheen 7s ease-in-out infinite;
}

@media (prefers-reduced-motion: reduce) {
  .crest--shine::before { animation: none; }
}
