# Ahom Reels 28–213: Google Flow prompts

One reel for every scene that has no film yet, in the order the events happened, continuing from reel 27. Mula Gabharu (AHOM-240) is left out because reel 27 already covers her.

## How to use in Flow

1. **Ingredients:** add the character sheets named under each reel, plus that scene's painting as the reference image. The `AHOM-…` code is the painting: `media/scenes/<era>/AHOM-…webp`.
2. **Prompt:** paste the block exactly. It already holds the hook, the action, the spoken line and the closing poster frame.
3. **Style line:** add this to the end of every prompt:
   > Vertical 9:16, cinematic, photoreal. No text, no subtitles.
4. Characters marked *(no sheet)* are described in the prompt itself, so they need no ingredient.

## Rules for a scroll stopper

- **Second 0 is already moving.** Every prompt opens mid-action, on a close-up or an impact. There are no establishing shots and no slow fades.
- **One turn.** Each reel has a single surprise: a betrayal, a reveal or a reversal, before the ninth second.
- **One spoken line, in Assamese.** It is short enough to say in about three seconds. The English under each block is for your caption.
- **The ending is a still poster frame with no text.** Flow garbles letters, so add titles in your editor.
- Graphic deaths (executions, torture, blinding) **cut away before the blow**. Platforms suppress gore, and the cut is the stronger hook anyway.

Have an Assamese speaker check the lines before you publish.
